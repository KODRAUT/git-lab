# git-lab

Демонстраційний проєкт для лабораторної роботи 11–12 з Git (дисципліна «Вступ до спеціальності», СумДУ).
Репозиторій містить просту програму на **C++**, яка рахує рядки та слова в текстовому файлі.

## Встановлення
Клонуйте репозиторій та відкрийте файл main.cpp.

## Використання
Скомпілюйте main.cpp (наприклад, `g++ main.cpp -o textstat`) і запустіть, передавши назву файлу:
`textstat input.txt`
